# 别眨眼 · BLINK

原创 Coser 主题「123 木头人」生存小游戏。

[在线游玩](https://inginnng.github.io/blink-coser-game/) · [GitHub 仓库](https://github.com/Inginnng/blink-coser-game)

双击 `index.html` 即可离线游玩。点击按钮或按空格闭眼，恢复完成后自动睁眼。睁眼时角色冻结，闭眼时角色向出口移动；睁眼越久，眼睛越干，闭眼恢复也越久。角色完全离开画面则结束，以存活时间排名。

排行榜保存在当前浏览器本机，没有服务器或全球排名。浏览器无法持久存储时，仍可游玩并保留本次打开期间的记录。昵称在游戏开始前填写，结算自动保存前 8 名。

按 `Space` 或点击「眨一下」闭眼；按 `P` 暂停或继续。切换窗口会自动暂停，点击「继续盯住她」恢复。音效可在右上角开启或关闭。

`index.html` 包含代码和图像，不需要联网、安装依赖或另带素材文件。独立规则源码在 `engine.js`，素材原图与生成提示词在 `assets/`。规则验证：`node tests/engine.test.cjs`。

人物与场景为原创虚构，不指向现实事件的当事人。
